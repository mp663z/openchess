# Contract readings - September 25, 2026

These are implementation choices for previously under-specified task chains, not permission to send game data to a provider or to change OAuth/hosted-sync architecture. Verify each in its own task battery. Existing structured contracts take precedence; where a choice below would contradict their closed fields, amend the contract in a separately reviewed commit before implementation. Every effect still follows the task's independent verifier and CI gates.

## T0428 events

Use control-plane operation events, scoped to the replaceable control-plane boundary in `data/contracts/control-plane.yaml`. Do not fold in ADR-0003 offline log events or `import.yaml` telemetry. The event envelope is versioned, vendor-neutral metadata only: operation ID, an opaque event ID, timestamp, correlation ID, outcome, and a code only when the operation returned an error. Event names derive from declared control-plane operations and their outcomes. Never include chess content, provider key material, credentials, request/response bodies, or raw free text. Stable IDs make replay idempotent; unknown names/versions are refused without partial event publication. The contract task first defines exact schema, ordering, failure and rollback; do not infer that these events already emit on the shipped path.

## T0455 rate limit

Scope is public control-plane `identity.register` and `identity.login`, because they explicitly list `rate_limited`; not the existing `jobs/limit.yaml` background-job token bucket and not billing quota. Use a per-operation, per-normalized account identifier plus a separately keyed source-abuse bucket so an attacker cannot evade the account bucket by moving IPs; do not make raw account IDs or IPs observable in telemetry. A deterministic clock and injected policy make boundary/retry tests stable. A rejected attempt has no identity side effect; `rate_limited` remains distinct from `quota_exhausted`. Follow `control-plane.yaml`'s error shape, preserving the Idempotency-Key replay rule; never invent an HTTP status or public retry header where the merged source has no mapping. Policy thresholds/window, abuse handling and source normalization belong in a new versioned contract and must be tested, not claimed as preexisting requirements. Start with a conservative configuration, with an explicit operator policy rather than a silent hard-coded number. Do not promise a fixed retry time in the public contract without that policy.

## T0464 AI adapter

Scope is the vendor-neutral interface between local model orchestration and a chosen local or explicitly opted-in hosted provider, not the control-plane route endpoint itself. The control-plane route carries capability, policy and cost only, returns a provider kind/reference/estimate, and receives no chess content. Keep local inference usable with no network. Hosted BYOM may receive only the closed `byom.yaml` payload after fresh `cloud_off.yaml`, sensitive-collection and accepted-terms checks at send time; provider keys stay in the approved local custody and never enter responses or diagnostics. Normalize capability metadata and typed failures, preserving `cost_cap_exceeded`, `provider_unavailable`, malformed input and cancellation as distinct outcomes. No vendor-specific list, provider credential flow, paid invocation or expanded payload is implied by a contract-only task. Review OAuth/hosted-sync cost/privacy/scope decisions with the owner rather than taking them here.

## Existing import chains

- T0603: `game_id` is the index key; `content_sha256` covers the canonical record bytes including `source_id`, as implemented in `ingest/import_pgn.py`. Re-import across sources with the same game identity is therefore an update, not a duplicate: one current index entry, new provenance and content-addressed record, old file may remain. Same-source same-content is a visible no-op. Do not silently remove source identity from the hash.
- T0625: require at least one progress event on a successful 10k import and a terminal completed event after the final committed game; do not invent a per-game cadence, payload, wall-clock or memory bound in this task. An event before a mid-run refusal may exist but cannot claim uncommitted games. Error classification is by the global failure mapping: invalid PGN structure `malformed_request`, legal-grammar SAN that violates game rules `illegal_move`. The scenario's shorter error list needs a reviewed structured-contract amendment before the illegal SAN case is asserted as T0625 conformance.
- T0636: retain the current narrow rejection location `{file, game_number, line}` and per-file/T0537 count shape; total is the sum. Stable lexicographic order of normalized relative `.pgn` filenames for filesystem input; reject symlinks, subdirectories, path traversal and non-PGN files before effects. Empty folder is a zero-file/zero-total success; empty `.pgn` is a zero-count file_completed. Extension is case-sensitive to avoid ambiguous selection. Duplicate/update events cannot be invented outside the closed scenario list; the counts still reflect them. Illegal SAN should use global `illegal_move`, but first amend the scenario error list in a separately reviewed contract change.
- T0647: per-game commit is atomic. Earlier folder rejection records and their game_rejected telemetry persist when cancellation happens later; cancelling does not erase already-completed events, only omits completed for the cancelled run. Cancellation at or after the final game is a completed run, not a cancelled one; double cancellation is idempotent. If refusal completed before the cancellation boundary, the refusal outcome wins. Cancellation within an in-flight game discards that game and leaves the committed prefix. These are product-facing semantics to pin before T0649; do not turn the test seam into a public API without a separate contract.

## Privacy and production gaps

T0446 should not blanket-reject every short SAN-like string, because ordinary text overlaps heavily with `e4` and `Nf3`. Reject known chess fields and known move/FEN payloads by schema and provenance before generic free-text detection; prevent game text from entering control-plane responses by construction. Key-shaped string values are not reliably identifiable by a universal regex: use write-only field schema, explicit secret sets, and whole-message redaction at log/error sinks; fail closed on undeclared response fields that look like credential fields. Preserve the documented limits of detection rather than claiming every short secret or encoded secret is caught. Production-vs-reference divergences in the T0561/T0572/T0583/T0594/T0605/T0616 implementation chains are bugs to fix in separate reviewed production commits against their already landed reference behavior, not grounds to weaken tests or redefine a closed contract.
