# T0006 No silent writes - evidence

Invariant + reference implementation: docs/governance/no-silent-writes.md, brand/approval.py.
- propose() computes the visible diff (before/after + diff hash); approve() binds an approval to the exact diff hash; commit() raises SilentWriteError without a matching approval.
- Approvals are single-use; diff changes invalidate approvals; every commit lands in an audit log.
- Product core will implement the same gate per ADR-0001.

Tests (tests/test_no_silent_writes.py, 4): unapproved write raises; approved write commits and audits; approval binds to exact diff; approvals single-use.
Verification: independent review - routed to the verifier with the merge SHA.
Commands: `pytest tests/test_no_silent_writes.py -q`.
