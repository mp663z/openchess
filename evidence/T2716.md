# T2716 Streaming decompression - evidence

Implementation: ingest/streaming.py
- iter_pgn_games: chunked zstd/plain reads (1MiB default), yields one PGN game at a time; buffer holds at most one partial game plus one chunk.
- Importer: sqlite sink, game_pk = sha256 of normalized text, INSERT OR IGNORE => cancel/restart re-reads bytes but never duplicates rows; import_runs journal records emissions/inserts per run.

Acceptance -> test mapping:
- "bounded memory": test_bounded_memory_on_multimegabyte_input - tracemalloc peak < 4MB and < raw input size on a multi-MB fixture.
- "survives cancellation/restart without duplicate rows": test_restart_after_cancel_no_duplicate_rows - import cut at 120/200 games, full re-import yields exactly 200 distinct rows.

Commands: `pytest tests/test_ingest_streaming.py -q`
Environment: python 3.11, zstandard 0.25.0 (MIT), sqlite3 stdlib.
