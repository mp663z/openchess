# T2719 Position indexing - evidence

Implementation: ingest/positions.py (pure python, no chess-library dependency; python-chess is GPL-3.0 and would fail the permissive-only license audit, bulletchess has no wheel for this platform).
- Canonical position key = board|turn|castling|en_passant. Half/full-move counters stored as metadata, excluded from identity.
- repertoire_key = sha256 of exact move sequence: same position via different move orders shares the position key but keeps distinct repertoire paths.
- FEN strictly validated (8 ranks, width 8, turn w/b, castling subset, ep square or -); malformed rejected, not repaired.

Acceptance -> tests (tests/test_positions.py, 7 tests): turn/castling/en-passant each shown to change the key; counters shown not to; move-order context test indexes one position with two distinct repertoire paths.

Commands: `pytest tests/test_positions.py -q`. Environment: python 3.11, stdlib only.
