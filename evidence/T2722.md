# T2722 Incremental update job - evidence

Implementation: ingest/incremental.py
- State db records applied (snapshot_id, sha256, url). New pins ingest once; same hash skips; changed hash for a known snapshot is a recorded conflict and is NOT ingested (fail-closed per pin policy).
- Every apply() writes a delta manifest JSON (schema_version 1) with per-snapshot actions and counts.

Acceptance -> tests (tests/test_incremental.py, 4 tests): initial ingest + delta manifest on disk; idempotent rerun; monthly increment ingests only the new snapshot; tampered hash recorded as conflict.
Commands: `pytest tests/test_incremental.py -q`. Environment: python 3.11, stdlib only.
