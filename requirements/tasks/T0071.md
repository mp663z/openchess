# T0071 Chess/en-passant/implement

## Normative requirements

1. `graph.en_passant` implements `EnPassantError`, `apply(state, move)`, `identity_value(state)`, `turn_transition(move_type, side)`, `NONE` and `FAILURE_MAPPING` for data/contracts/en_passant.yaml. Every table it uses (failure mapping, set-on ranks, mover ranks, turn linkage) is read from the contract, never restated. It imports no `tests.*` module.
2. Every T0069 fixture row (happy, boundary, malformed, rollback) gives the pinned result or the pinned failure class and mapped error.
3. Parity with the T0069 reference interpreter (`tests.test_t0069_en_passant_fixture._apply`, `_identity_value`, `_expected_turn`): same outcome by value and failure class over every fixture row and a generated sweep of more than 20000 cases (every fixture state with each declared, off-rank and malformed target, both sides, and every move type to and from a spread of squares), plus extra states the fixture lacks (blocked pin lines, non-pawns on the start ranks).
4. The T0070 red tests pass with their `_apply` bound to the runtime.
5. Atomicity: no call mutates its inputs (value, key order, object identity at every level) and no output shares an object with an input.
6. Hostile input fails closed as a typed `target_malformed` at every level and through every entry point: non-dict and dict-subclass state, move and occupied map; str-subclass keys and values; a key that hashes like a field name and whose `__eq__` raises; extra, missing and renamed keys; unknown squares, pieces, sides and move types; `None` fields; not exactly one king per side; a move whose from-square is empty. Key types are checked before any set build or comparison, so a hostile key's methods never run.
7. A forged `EnPassantError` never passes through: the raised error is fresh (not the forged object) and has no `__cause__`. `__context__` is not asserted.

## Closed-domain catch-all

The contract's failure classes cover the en-passant rules only. Inputs outside the closed domain (hostile types, unknown squares or pieces, a move from an empty square, a bad turn-transition argument) all map to `target_malformed` (`malformed_request`), the contract's "not canonical" class. The reference agrees on every well-typed sweep case.

## Forge scope

Per module: graph/en_passant.py raises only `EnPassantError` and its one except clause (the identity probe in `identity_value`) names only `EnPassantError`. The AST test pins both sets. The forged error is raised from a hostile key's `__eq__` at the state, move and occupied-map levels.

## Mutants

This list is prose only. `MUTANTS` in the test file is the authority. Each is a one-line source edit of graph/en_passant.py, run with bytecode caching off, and each is killed by the fixture rows, the parity sweep, identity and turn parity, or the hostile battery.

- Input validation: exact-dict check made isinstance; key-type check removed; key set equality weakened to superset; side check removed; occupied map check made isinstance; square domain, piece domain and king-count checks removed; move-type and move-square domain checks removed; target grammar rank check removed; no-piece check removed.
- Capture: the none-target class changed; availability (target rank) check removed; captured-pawn check removed; destination check removed; mover-rank check removed; adjacency check removed; mover-piece check removed; captured pawn kept on the board; pin check removed; slider blocking ignored; target kept after the capture.
- Move application: target retained after a move; set-on pawn, file and move-type checks removed.
- Identity: always the stored target; only the first neighbouring file probed.
- Turn transition: halfmove clock always reset; fullmove increment for either side; move-type domain check removed.

No equivalent edits are claimed.
