# T0097 Chess/SAN/red test

## Normative requirements

1. tests/test_t0097_san_red.py holds executable SAN mutants. Each wraps the T0095 contract reference (`resolve_san`, `emit_san`) and implements exactly one named defect.
2. The T0096 fixture, plus ten T0097-local rows in the same schema (`LOCAL_ROWS`), is the oracle. The local rows cover contract semantics the fixture lacks: a mating move whose SAN is `Ra8#` (san.yaml suffix: "#" iff the move mates), the same move claimed as `Ra8+` (no_legal_match / illegal_move), and ` e4` / `e4 ` (a body is exactly one declared form: malformed_san / malformed_request), a missing required suffix (`Ra8` on the mate state, `O-O-O` where it checks: no_legal_match), promotion without `=` (`a8Q`) and a lowercase promotion piece (`a8=q`) (malformed_san), a capture mark on a quiet move (`Nxf3`: no_legal_match), and king-move castling notation (`Kc1`: no_legal_match). Classes are read from the reference. A row fails when resolve gives a different move, emit gives a different string, a rejection has a different failure class or mapped error code, a malformed row's repair does not resolve and emit back to itself, or the caller's state changes (value or key order).
3. The reference fails no row. Every mutant fails a pinned, non-empty set of rows (`EXPECTED_KILLS`). Every malformed and rollback row is in at least one set.
4. Named red tests show each key defect against the reference: lowercase piece letter, guessed ambiguous move, false suffix claim, castling suffix without the rook hop, rank-first disambiguation, checkmate written as check, surrounding whitespace accepted, (and via the pinned kill sets) optional suffix, promotion without `=`, lowercase promotion, capture mark ignored, king move as castling, and a rejection that corrupts state (with a witness that the mutant really corrupts it).
5. Round-trip sweep: every legal move (castling included) of every distinct fixture and local state, 112 moves, emits a SAN that resolves back to the same move without changing the state.
6. `RESOLVE`/`EMIT` are the binding points. T0098 switches them to the runtime; nothing else in the file changes.

## Scope

No production entry point exists yet (T0098 implements it), so the hostile-type rows of the standing battery rule, the forge set and source mutants of a production module come with T0098. The mutants here are behaviour mutants of the reference, the T0070 pattern.

## Mutants

This list is prose only. `MUTANTS` and `EXPECTED_KILLS` in the test file are the authority.

- Resolve: accept lowercase piece letter; accept digit-zero castling; pick the first of several matches; ignore a false suffix claim; accept over-disambiguation; strip annotation glyphs; fall back to a nearest move; mutate the state on rejection; drop the promotion piece; collapse every failure to no_legal_match; wrong error code for the class.
- Resolve (continued): strip surrounding whitespace; suffix optional; promotion without `=`; lowercase promotion piece; capture mark ignored; king-move notation read as castling.
- Emit: drop the suffix; checkmate written as check; rank-first disambiguation; pawn capture without its origin file.
- Both: castling applied without the rook hop (restored after each call; a test pins that).

No equivalent mutants.
