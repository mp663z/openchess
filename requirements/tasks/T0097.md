# T0097 Chess/SAN/red test

## Normative requirements

1. tests/test_t0097_san_red.py holds executable SAN mutants. Each wraps the T0095 contract reference (`resolve_san`, `emit_san`) and implements exactly one named defect.
2. The T0096 fixture is the oracle. A row fails when resolve gives a different move, emit gives a different string, a rejection has a different failure class or mapped error code, a malformed row's repair does not resolve and emit back to itself, or the caller's state changes (value or key order).
3. The reference fails no row. Every mutant fails a pinned, non-empty set of rows (`EXPECTED_KILLS`). Every malformed and rollback row is in at least one set.
4. Named red tests show each key defect against the reference: lowercase piece letter, guessed ambiguous move, false suffix claim, castling suffix without the rook hop, rank-first disambiguation, and a rejection that corrupts state (with a witness that the mutant really corrupts it).
5. Round-trip sweep: every legal move (castling included) of every distinct fixture state, 95 moves, emits a SAN that resolves back to the same move without changing the state.
6. `RESOLVE`/`EMIT` are the binding points. T0098 switches them to the runtime; nothing else in the file changes.

## Scope

No production entry point exists yet (T0098 implements it), so the hostile-type rows of the standing battery rule, the forge set and source mutants of a production module come with T0098. The mutants here are behaviour mutants of the reference, the T0070 pattern.

## Mutants

This list is prose only. `MUTANTS` and `EXPECTED_KILLS` in the test file are the authority.

- Resolve: accept lowercase piece letter; accept digit-zero castling; pick the first of several matches; ignore a false suffix claim; accept over-disambiguation; strip annotation glyphs; fall back to a nearest move; mutate the state on rejection; drop the promotion piece; collapse every failure to no_legal_match; wrong error code for the class.
- Emit: drop the suffix; rank-first disambiguation; pawn capture without its origin file.
- Both: castling applied without the rook hop (restored after each call; a test pins that).

No equivalent mutants.
