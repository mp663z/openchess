# T0106 Chess/UCI/red test

## Normative requirements

1. tests/test_t0106_uci_red.py holds 24 executable UCI mutants. Each patches one function of the T0104 contract reference (tests.test_t0104_uci_contract: the frame reader, line check, move and integer grammar, GUI/engine parsers, emitter, session steps) with exactly one named defect. Every patch is restored after each call, and a test checks that.
2. The oracle is 231 rows: every T0105 fixture row (malformed rows also check their repair), plus T0106-local rows built from the reference's own pinned lists: 80 parse-and-emit round trips (fixture and HAPPY_GUI/HAPPY_ENGINE), MALFORMED_GUI and MALFORMED_ENGINE (malformed_line), UNKNOWN (unknown_command), POSITION_SUBCLASSES (malformed_line with the FEN subclass kept), FRAMING_MALFORMED plus unterminated and byte-by-byte framing, the full HAPPY_TRACE session with its states, and 10 out-of-order session events (protocol_state, the session unchanged in value and snapshot). Each rejection checks failure class, mapped error code and subclass.
3. The reference fails no row. Every mutant fails a pinned, non-empty row set (`EXPECTED_KILLS`). Every fixture malformed and rollback row and every session row is in at least one set.
4. Named red tests show key defects against the reference with a witness: CRLF at the framing layer, a UTF-8 sequence split across chunks, unknown keyword keeping its own class, and a rejected session event that corrupts state.
5. `BINDING` names what the oracle calls (parse_gui, parse_engine, emit, FrameReader, Session). T0107 rebinds them to the runtime.

## Scope

No production UCI entry point exists yet (T0107 implements it). Per the coordinator's T0097 ruling, hostile-type rows, the forge set and source mutants of a production module come with T0107. The mutants here are behaviour mutants of the reference (T0070/T0097 pattern).

## Mutants

This list is prose only. `MUTANTS` and `EXPECTED_KILLS` in the test file are the authority.

- Framing: CRLF accepted; empty frame accepted; invalid UTF-8 replaced; buffer reset per chunk; unterminated bytes accepted.
- Line grammar: runs of spaces collapsed; edges stripped; keyword case folded; any lowercase promotion letter; leading zeros accepted; pos-int allows zero.
- Parse/emit: unknown reported as malformed; `bestmove (none)` rejected; ponder dropped; score sign lost; emit drops ponder; FEN subclass dropped; wrong error code.
- Session: unlisted pair ignored; isready queued while pending; go ignores the position requirement; ucinewgame keeps the position; unrequested readyok accepted; a rejected event mutates the session.

No equivalent mutants.
