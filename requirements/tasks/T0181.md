# T0181 Graph/diff/fuzz/fault

## Normative requirements

1. The battery is deterministic and seeded. It fuzzes the shipped production diff (`graph.diff`, T0179). It builds every state and diff from an independent model of data/contracts/diff.yaml: the state-id derivation and the diff sections are restated in the test, never taken from production. The contract reference engine (`tests.test_t0176_diff_contract`) serves as the differential oracle.
2. Generators:
   - `compute`: two states, one of them hostile. This covers non-dict and dict-subclass containers and one tampered entry: str-subclass, hash-colliding, int and mismatched keys; extra and missing fields; non-str and str-subclass field values; bad and foreign digests; clocks; bad FENs; unknown variants; dict-subclass and non-dict records.
   - `validate`: a model diff with one tamper (fields, ids, sections, entries, changed witnesses, overlaps, empty/non-empty id agreement), run through `validate_diff` and `apply`. It includes str-subclass and colliding keys at the diff, section and witness levels.
   - `apply`: a model diff over a damaged base: extra, missing and swapped records; an added identity already present; a forged base id over an absent removed identity; a lying target id; a hostile base.
   - `state_id`: model states and hostile states.
   - `linked`: each linked call (`parse_position`, `identity`, `digest_fen`, and the entry listing) raising every BaseException kind, or raising a forged typed error of every class the module or its linked modules raise.
3. Every case holds against production:
   - No raw escape: only a typed `DiffError` from the closed class set, carrying its mapped code. It is never a forged error object and never has an explicit `__cause__`. `__context__` is not asserted (wal ruling).
   - The same outcome as the contract reference, where the reference applies.
   - The independently known outcome, where there is one.
   - Outputs equal the model in canonical key order and share no object with any input.
4. Atomicity: every call leaves every input identical by value, exact type, key order and object identity at every level.
5. No poisoning: after any rejection, a fresh call still handles a clean input correctly. Outcomes are deterministic by value.
6. Happy round trips: compute then apply reproduces the target, and the result matches the model. Boundaries are covered.
7. Mutation check: `_probe` runs a fixed slice of every generator against a source mutant of graph/diff.py. For `linked`, the slice is every fault at every link. The identity mutant must pass. Every mutant in `MUTANTS` must fail, and every entry in `_EQUIVALENT_EDITS` must pass.

## Reference scope

The T0176 reference checks only the digest grammar. It does not check that a digest belongs to its record. So the foreign-digest cases (31 in the current corpus) (a well-formed digest of another position) skip the reference comparison and are checked only against the independently known outcome, `malformed_diff_record`. Closing that gap in the reference is a separate follow-up.

## Production changes

- `_exact_str_keys` key-type guard at the record, diff and witness levels. It runs before any set or hash comparison, so a str-subclass key, or a key whose hash collides with a field name and whose `__eq__` raises, fails closed as `malformed_diff_record` instead of comparing or escaping raw.
- Both `except BaseException` boundaries (the record boundary and the entry-listing boundary) now raise `DiffError("malformed_diff_record") from None` instead of `from error`. Every other engine rejects with no explicit `__cause__`, and graph/diff.py was the only one that chained. This change applies the same freshness rule everywhere with no exemption, as ruled by the coordinator. The unused `as error` binding goes too.

## Requirement-to-test mapping

- R1 to R5: `test_fuzz_cases_hold` (every generator, in chunks of 48 seeds), `test_determinism_by_value`, `test_corpus_reaches_every_class_and_every_edit`.
- R6: `test_happy_round_trips_match_the_model`, `test_boundaries`.
- R7: `test_identity_source_mutant_is_green`, `test_mutant_is_red`, `test_equivalent_edits_stay_green`.

## Mutants

This list is prose only. `MUTANTS` in the test file is the authority.

Record and listing boundaries (the two `except BaseException` sites), for each site:
- `except DiffError: raise` ahead of the catch-all. `except Exception` instead of `BaseException`.
- The typed failure re-raised `from error` (cause chain).
- One forged-class passthrough per class: every `DiffError` class, every `DigestError` class, every `VariantError` code, and `ContractError`.

Record: isinstance for the record type; field set replaced; the key guard removed; the str-value check removed or isinstance; clock check weakened; digest binding removed; key identity removed; key type check removed; state isinstance.

Diff: isinstance; the field set removed; the key guard removed; id grammar removed or isinstance; empty/non-empty id agreement removed or misclassed; sections removed; changed witness type, shape, key guard, identity and equality checks removed; overlap check removed.

State id: validation removed; fields out of order.

Compute: no copy; sides swapped; entries unsorted.

Apply: validation removed; base-id and target checks removed; removed-unknown and added-present checks removed; in-place mutation; shallow staging; added entries not copied.

Equivalent edits (asserted green):
- Dropping `_validate_state(base)` in `apply`: `state_id(base)` validates the base again before any use.
- Dropping the digest grammar check: a grammar-breaking digest can never equal the linked `digest_fen` output.
- Dropping the FEN six-field count: the linked parser rejects such a FEN at the record boundary as `malformed_diff_record`.
- No copy of a changed witness target in `apply`: every exact valid record is identity-derived, so no changed witness can reach apply.

## Forge scope

Per module: every class graph/diff.py raises itself (`DiffError`) plus every class named in its own except clauses (`BaseException` only; no builtin is named). The linked `DigestError`, `VariantError` and `ContractError` are forged too, because they cross the record boundary.
