# T0188 Graph/conflict/implement

## Normative requirements

1. `graph.conflict` implements `ConflictError`, `ConflictDetector().detect(base, left, right)`, `state_id(state)`, `load_docs()` and `FAILURE_MAPPING` for data/contracts/conflict.yaml (contract id `graph-conflict`). It links only the shipped `graph.node`, `graph.position_digest` (for `DigestError`) and `tools.variant_runtime` runtimes and never imports `tests.*`.
2. Every state is validated before any change is derived. A state is an exact dict. Each key must be an exact str. Each value must be an exact dict whose keys are exact str (checked before any set build), exactly `{variant, digest, snapshot_fen}` with exact-str values. The record's variant and snapshot must equal the `graph.node.make_record` derivation. The digest must match the linked format; it is format-checked only and never decides identity or compatibility. The key must equal the canonical identity (`repr` of the `tools.variant_runtime` identity projection, the same key graph.node and graph.diff use). The linked runtime's rejections (`VariantError`, `DigestError`, and the raw `ValueError` on a clock beyond the integer-string limit) map to a FRESH, unchained `malformed_conflict_record`.
3. State ids are derived from the validated content (sha256 over the sorted identity to sorted-field serialization, `gs1:` grammar); they are never caller supplied. `divergent_base` fails closed when the base id equals either side id; left equal to right is an identical outcome and compatible. Changes are identity-keyed against the base. Every overlapping identity with different outcomes is reported as `{kind, left, right}` (`both_changed_differently`, `changed_vs_removed` with `null` for the removing side, or `added_differently`). Witnesses are in canonical identity order. Detection is deterministic and left-right symmetric (a swap flips the witnesses), never mutates or re-binds its inputs, and never resolves a conflict.
4. The T0187 red battery turns green by replacing only its two binding lines with `from graph.conflict import ConflictDetector, ConflictError` (the line carries `# noqa: E402  # isort: skip` so ruff keeps it in place).

## Red/green transition

On parent main, switching the T0187 binding to `graph.conflict` fails at import because the module does not exist. With this change the same switch passes all T0187 tests.

## Divergence from the contract reference

The T0185 reference lets the linked parser's raw `ValueError` escape on a clock beyond 4300 digits. Production fails closed as `malformed_conflict_record`, matching the T0125 ruling. On every fixture row and probe the two agree otherwise.
