# T0197 Store/migration/implement

## Normative requirements

1. `store.migration` implements `MigrationError`, `MigrationEngine(target_oracle)` with `migrate(request, source_state)`, `pdv2_digest` (the honest store-v2 oracle), `state_id`, `derive_migration_id` and `FAILURE_MAPPING` for data/contracts/migration.yaml. Production must not import or execute `tests.*`.
2. The request is an exact dict with exact-str keys `{from_schema, to_schema, source_id}`: registered schema ids in the pinned grammar and a state id in the pinned grammar, or it fails `malformed_migration_record`. A pair with no registered step (including no-op and downgrade) fails `unknown_migration`.
3. The source must be an exact dict of exact-str identities to exact node records. Variant and snapshot must be canonical through the shipped graph.node runtime (with the same rejection set the other store modules use), the digest must be in the source schema's grammar, and the derived identity must equal the key. Otherwise `malformed_migration_record`. The recomputed source state id must equal the request's, or it fails `conflicting_source`.
4. The target oracle is untrusted: exactly one call per retained key on the frozen source. Any BaseException, or output that is not an exact str in the target digest grammar, fails `divergent_target`. The staged state is validated against the target schema, the identity set and the cardinality, or it fails `divergent_target`.
5. The request and source are restored bit- and reference-identical on every exit. The receipt carries the staged state and a locally derived `target_id` and `migration_id`.
6. The T0196 red battery turns green by replacing only its two binding lines. Every scenario, probe and mutant stays unchanged (on top of the bound-error mutant fix in #246).

## Requirement-to-test mapping

- R1: `test_r2_production_imports_only_shipped_runtimes`, `test_r3_public_surface`.
- R2 to R5: the full T0196 battery (`tests/test_t0196_migration_red.py`) bound to `store.migration`, plus `test_r4_reproduces_every_pinned_receipt` and `test_r5_state_id_is_the_graph_diff_serialization`.
- R6: `test_r1_red_battery_switch_is_exactly_the_two_binding_lines` (with the two lines switched back, the file hashes to the merged T0196 version).

## Red/green transition

On parent main, switching the two T0196 binding lines to `store.migration` fails at import because the module does not exist. With this change the same switch passes all 45 T0196 tests.
