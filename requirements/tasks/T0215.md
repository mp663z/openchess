# T0215 Store/WAL/implement

## Normative requirements

1. `store.wal` implements `WalError`, `WalEngine(payload_canonicalizer)` with `append(log, request)` and `replay(log)`, `canonical_payload`, `GENESIS` and `FAILURE_MAPPING` for data/contracts/wal.yaml. Production must not import or execute `tests.*`. Record validation and identity come from the shipped `graph.node` runtime and the replay state id from `graph.diff.state_id`.
2. Validation precedence matches the T0212 contract: exact entry shape (exact-str key guard before any set or hash comparison), registered op, exact 1-based sequence, id grammars, prior link, then payload and exact linked record; chain re-derivation behind the oracle boundary follows.
3. The payload canonicalizer is untrusted: exactly one call per entry per operation, detached argument copies, any BaseException or non-exact-str or non-UTF-8 output fails closed as `divergent_canonicalization`.
4. append and replay are atomic: a rejection leaves log and request bit- and reference-identical; append commits last and returns a receipt that aliases neither the log entry nor the request.
5. The T0214 red battery turns green by replacing only its production-bindings import. Every scenario, closure check, probe and mutant stays unchanged.
6. The memoized linked derivation (pure and keyed only on exact-str inputs) never changes an outcome and never hands out a shared object. It caches successes only: a transient failure (e.g. MemoryError) is never memoized, only the linked runtime's caller-input rejections (VariantError, DigestError, ValueError) map to malformed_wal_entry and any other exception propagates, and inputs longer than 256 (FEN) / 64 (variant) characters bypass the memo so it never retains unbounded caller bytes.

- R6: `test_r4_memoized_linked_derivation_is_detached`, `test_r4_memo_never_accepts_a_wrong_digest_after_a_good_one`, `test_r6_transient_failure_is_not_memoized`, `test_r6_non_contract_bug_propagates_not_blamed_on_caller`, `test_r6_memo_bytes_bounded_and_rejections_never_cached`. Each r6 test then runs the whole T0214 fixture manifest (happy, boundary, malformed, rollback and append-onto-corrupt-log rows) on the same engine instance.

## Red/green transition

On parent main, switching only the T0214 binding line to `store.wal` fails at import because the module does not exist. With this change the same one-line switch passes all 125 T0214 tests.
