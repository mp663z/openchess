# T0224 Store/backup/implement

## Normative requirements

1. `store.backup` implements `BackupError`, `BackupEngine(bundle_serializer)` with `backup(log)` and `verify(receipt)`, `serialize_bundle`, `derive_backup_id`, `GENESIS`, `EMPTY_STATE_ID` and `FAILURE_MAPPING` for data/contracts/backup.yaml. Production must not import or execute `tests.*`.
2. Source validation and replay go through the linked production WAL (`store.wal`); any WAL rejection surfaces as `corrupt_source`. The replayed state is frozen and detached before the single untrusted serializer call; any BaseException, non-exact-str or non-UTF-8 output fails closed as `divergent_snapshot`.
3. verify is local and total: exact five-field shape with the exact-str key guard first, pinned grammars, entry_count bounded to the int64 ceiling before any conversion, head/count consistency, then the recomputed backup id must equal the stored one. It makes no serializer calls.
4. Rejected backup or verify leaves every input bit- and reference-identical; the engine instance keeps behaving correctly after any rejection.
5. The public `derive_backup_id` reproduces every pinned T0222 receipt's backup id.
6. The T0223 red battery turns green by replacing only its production-bindings block. Every scenario, closure check, probe and mutant stays unchanged.

## Requirement-to-test mapping

- R1: `test_r2_production_imports_only_shipped_runtimes_and_links_wal`, `test_r3_public_surface`.
- R2: `test_r5_corrupt_source_surfaces_from_the_linked_wal` and the T0223 battery.
- R3, R4: the full T0223 battery (`tests/test_t0223_backup_red.py`) bound to `store.backup`, including the 58 totality probes and 22 engine mutants.
- R5: `test_r4_derive_backup_id_reproduces_every_pinned_receipt` and T0223 `test_forgery_derivation_is_faithful`.
- R6: `test_r1_red_battery_switch_is_only_the_bindings_block` (the file with the block switched back hashes to the #217 merge version).

## Red/green transition

On parent main, switching only the T0223 bindings block to `store.backup` fails at import because the module does not exist. With this change the same switch passes all 170 T0223 tests.
