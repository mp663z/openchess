# T0251 Store/export/implement

## Normative requirements

1. `store.export` implements `ExportError`, `ExportEngine(exporter)` with `export(log, request)`, `render_document` (the canonical rendering and honest exporter), `derive_export_id`, `FORMATS` and `FAILURE_MAPPING` for data/contracts/export.yaml. Production must not import or execute `tests.*`.
2. The log must be an exact list and the request an exact dict whose keys are checked as exact str before the set compare, with an exact-str `format`; otherwise `malformed_export_request`. A format outside the closed list is `unsupported_format`. These checks run before the source is read.
3. Source validation and replay go through the linked production WAL (`store.wal.WalEngine.replay`); any WAL rejection surfaces as `corrupt_source`. Input preservation uses the WAL's public `snapshot` / `restore` helpers, never its private names.
4. The exporter is untrusted: exactly one call on a detached by-value copy of the frozen state and the exact format; any BaseException, non-exact-str or non-UTF-8 output, or a document not byte-equal to `render_document(frozen state, format)`, fails closed as `divergent_export`.
5. Every export leaves log and request bit- and reference-identical and returns `{export_id, head, state_id, record_count, format, document}` with `export_id` derived locally.
6. The T0250 red battery turns green by replacing only its two binding lines. Every scenario, probe and mutant stays unchanged.

## Requirement-to-test mapping

- R1: `test_r2_production_imports_only_shipped_runtimes_and_links_wal`, `test_r3_public_surface`.
- R2, R4, R5: the full T0250 battery (`tests/test_t0250_export_red.py`) bound to `store.export`, plus `test_r4_reproduces_every_pinned_receipt`.
- R3: `test_r2_production_imports_only_shipped_runtimes_and_links_wal` (only names in `store.wal.__all__` are used), `test_r5_corrupt_source_surfaces_from_the_linked_wal`.
- R6: `test_r1_red_battery_switch_is_exactly_the_two_binding_lines` (with the two lines switched back, the file hashes to the merged T0250 version).

## Red/green transition

On parent main, switching the two T0250 binding lines to `store.export` fails at import because the module does not exist. With this change the same switch passes all 51 T0250 tests.
