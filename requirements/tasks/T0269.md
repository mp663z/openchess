# T0269 Store/corruption/implement

## Normative requirements

1. `store.corruption` implements `CorruptionError`, `CorruptionEngine(quarantine_sink)` with `scan(log, request)`, `canonical_encoding`, `quarantine_suffix`, `derive_scan_id` and `FAILURE_MAPPING` for data/contracts/corruption.yaml (contract id `store-corruption`). Production must not import or execute `tests.*`.
2. The request is an exact dict with exactly one exact-str key `max_loss`, whose value is an exact built-in int of at least 0. Key types are checked before any hashing comparison. The log is an exact list inside the closed canonical-encoding domain (exact None, bool, bounded int, UTF-8-encodable str, list, and dict with exact-str keys; bounded depth; no cycles or aliases). Anything else is `malformed_corruption_record`.
3. Detection is the linked production WAL: the verified prefix is the longest prefix that `store.wal.WalEngine(canonical_payload).replay` accepts, and `verified_head` is that replay's head, or `GENESIS` for an empty prefix. Only names in `store.wal.__all__` are used. WAL validation is prefix-monotone, so a binary search gives the same count as a linear search.
4. A fully verified log returns a `clean` receipt with no sink call and no mutation. A corrupt suffix longer than `max_loss` fails `excessive_loss` with no sink call.
5. The quarantine sink is untrusted: exactly one call on a detached copy of the frozen corrupt suffix. Any BaseException, non-exact-str, wrong-grammar or UTF-8-unencodable output, or a token that is not byte-exact to `quarantine_suffix(frozen_suffix)`, fails closed as `divergent_quarantine`. Log and request are restored bit- and reference-identical on every exit. On success the suffix is removed last and a `salvaged` receipt is returned, with `scan_id` re-derived from its fields.
6. The T0268 red battery turns green by replacing only its two binding lines. Every scenario, probe and mutant stays unchanged.

## Red/green transition

On parent main, switching the two T0268 binding lines to `store.corruption` fails at import because the module does not exist. With this change the same switch passes all 80 T0268 tests.
