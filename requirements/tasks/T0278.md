# T0278 Store/crash resume/implement

## Normative requirements

1. `store.crash_resume` implements `ResumeError`, `ResumeEngine(quarantine_sink)` with `resume(log, request)`, `quarantine_tail` and `FAILURE_MAPPING` for data/contracts/crash_resume.yaml (contract id `store-crash-resume`). Production must not import or execute `tests.*`.
2. The log is an exact list. The request is an exact dict whose keys are exact strs (checked before any set or hash comparison) and equal `{checkpoint_sequence}`, with an exact built-in int value. Otherwise `malformed_resume_record`. A negative checkpoint is `unknown_checkpoint`. A checkpoint past the log length is `corrupt_source`.
3. The surviving prefix is the longest prefix the linked production WAL (`store.wal.WalEngine(canonical_payload).replay`) accepts, capped at the first entry that fails the total admission walk (exact built-in JSON values, exact-str UTF-8 keys, ints of at most MAX_INT_DIGITS digits, finite floats, depth at most MAX_DEPTH, no container met twice anywhere in the entry). The walk is iterative and never raises. Only names in `store.wal.__all__` are used. A prefix shorter than the checkpoint is `corrupt_source`. A torn tail with an inadmissible entry is `malformed_resume_record`.
4. The torn tail is frozen to detached canonical copies before the snapshot. The untrusted sink gets exactly one call on a detached copy. Any BaseException, non-exact-str or wrong-grammar output, or a token that is not byte-exact to `quarantine_tail(frozen_tail)`, fails closed as `divergent_quarantine`. Log and request (every nested container) are restored by value and by reference on every exit. The tail is removed last, and the receipt's `resume_id`, `head`, `state_id` come from the linked replay of the surviving prefix.
5. The T0277 red battery turns green by replacing only its two binding lines. Every scenario, probe and mutant stays unchanged.

## Red/green transition

On parent main, switching the two T0277 binding lines to `store.crash_resume` fails at import because the module does not exist. With this change the same switch passes all 106 T0277 tests.
