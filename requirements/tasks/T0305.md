# T0305 Jobs/cancel/implement

## Normative requirements

1. `server.jobs_cancel` implements `CancelError` and `cancel(request)` for
   data/contracts/cancel.yaml (contract id `jobs-cancel`). Production must
   not import or execute `tests.*`.
2. The request is checked first (`malformed_cancel_request`), then the job
   against every linked queue job invariant (`corrupt_job`), then the
   status (`job_not_cancellable`): exact types only, dict keys checked as
   exact strs before any set comparison, requester by ASCII fullmatch, now
   0..2**53-1, job id by ASCII fullmatch, seq 0..2**53-2, priority 0..9,
   attempts 0..max_attempts, a leased job needs a worker-grammar owner, an
   expiry 1..2**53-1 and attempts >= 1, a non-leased job holds neither,
   dead means attempts == max_attempts, done means attempts >= 1. The
   payload is exact canonical JSON: acyclic, alias-free, depth at most 64,
   int digits at most 4000, finite floats, UTF-8 strs, checked by an
   iterative walk that never runs caller code.
3. Only a valid job whose presented status is ready or leased is
   cancelled. The record carries op, job_id, seq, priority, the payload
   digest (`pd1:` plus the sha256 of the contract preimage, never a
   payload copy), status_before, attempts, requester, cancelled_at and a
   decision id (`cd1:` plus the sha256 of the contract preimage over the
   record), and no lease fields. Errors are fresh typed CancelErrors with
   no cause or context; the request is never changed.
4. The T0304 red battery turns green by replacing only its two binding
   lines. Every row, probe and mutant stays unchanged.

## Mutation check

90 single-token production mutants (comparison, boolean, return, offset,
operator and integer-literal swaps) were run against the T0304 battery
plus the runtime proof, stopping at each mutant's first failing test. 89
mutants are killed and none of them by a raw crash: a kill counts only
when the first failure is a semantic outcome, which is an assertion (55)
or a wrong typed refusal or detected caller-code run (34). Raw exceptions
(TypeError, KeyError, AttributeError and the like) are tallied separately
and there were 0 of them, so no mutant relies on a crash. The 1 survivor
is stated as behavior-equivalent: `MAX_INT_BITS` 13288 -> 13289 widens
only the bit-length pre-screen; every int it newly admits has more than
4000 decimal digits and is rejected by the exact digit check (verified by
a green full-suite run against the mutated source).

## Red/green transition

On main, switching the two T0304 binding lines to `server.jobs_cancel`
fails at import because the module does not exist. With this change the
same switch passes all 29 T0304 tests.
