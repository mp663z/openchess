# T0306 Jobs/cancel/unit/property

## Normative requirements

1. `tests/test_t0306_cancel_unit_property.py` proves happy, boundary, malformed and rollback behavior of the production `server.jobs_cancel.cancel` (T0305) with unit rows and seeded properties. It adds no production code.
2. Every call is compared with an independent model written from the contract (hand-built grammar and bound checks, a bounded payload walk, hand-built `pd1:`/`cd1:` digests; no shared code with production): same record, or same failure class with the mapped code, `retryable` false, no cause or context.
3. Every call leaves the request byte-identical and returns a record that shares no container with it.
4. Every request and job bound is pinned on both sides, hostile values (bool, float, NaN, bytes, tuple and object roots, str and int subclasses, inert str-subclass keys, missing, extra and non-str keys, payload aliases and cycles, lone surrogates) are refused with the right class at every field, and the failure precedence is request shape, then job integrity, then status.

## Requirement-to-test mapping

- Happy: `test_ready_record_is_exact_and_ordered`, `test_leased_record_carries_no_lease_fields`, `test_payload_digest_binds_the_payload_and_stores_no_copy`, `test_scalar_payload_roots_cancel_and_digest_exactly`, `test_no_jitter_and_determinism`, `test_decision_id_binds_every_request_field`, `test_result_shares_no_container_with_the_request_or_other_results`.
- Boundary: `test_job_int_bounds_are_exact`, `test_now_bound_is_exact`, `test_lease_invariants_are_exact`, `test_done_and_dead_invariants_are_exact`, `test_payload_depth_and_int_digits_are_exact` (list and dict nesting 64 vs 65, the largest 4000-digit int at the exact bit pre-screen boundary), `test_lowered_int_str_limit_fails_closed`.
- Malformed: `test_every_scalar_request_field_rejects_hostile_values`, `test_every_scalar_job_field_rejects_hostile_values`, `test_hostile_payload_roots_are_corrupt`, `test_payload_alias_and_cycle_are_corrupt`, `test_payload_hostile_scalars_are_corrupt`, `test_subclasses_of_exact_types_are_refused`, `test_inert_str_subclass_keys_are_refused_at_both_levels`, `test_missing_extra_and_non_str_keys_are_refused`, `test_non_dict_requests_are_malformed`, `test_requester_and_worker_grammar_is_exact`, `test_job_id_grammar_is_exact`, `test_precedence_request_then_job_then_status`.
- Rollback: `test_rejected_requests_change_nothing_and_a_valid_follow_up_cancels`, `test_result_shares_no_container_with_the_request_or_other_results`.
- Properties (seeded, replayable): `test_engine_matches_independent_model_on_random_requests` (40 seeds, half of the requests damaged), `test_record_fields_are_exact_functions_of_the_request`, `test_replay_is_deterministic_and_ids_are_unique_per_distinct_request`.

## Mutation check

91 single-token mutants of `server/jobs_cancel.py` (comparison, boolean, return, offset, operator and integer-literal swaps) were run author-side against this file alone, stopping at each mutant's first failing test; the generator and records are not checked in, so this census is author-run, not independently certified. 82 mutants are killed by semantic outcomes (an assertion, a model mismatch or a wrong typed class: 81 assertion, 1 wrong typed refusal). 7 are killed only by a raw exception: each is a wrong-accept sabotage (a guard flipped so a hostile value passes validation) whose wrongly-admitted input crashes downstream (TypeError/AttributeError/ValueError) before any record exists to compare; re-running each without stopping found no assertion failure. The 2 survivors are behavior-equivalent: `MAX_INT_BITS` 13288 -> 13289 widens only the bit-length pre-screen (every int it newly admits has more than 4000 decimal digits and is rejected by the exact digit check), and `ensure_ascii=True` -> `False` in the canonical encoder (every encoded string is ASCII by grammar).
