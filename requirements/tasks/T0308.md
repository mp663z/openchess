# T0308 Jobs/cancel/integration/restart

## Normative requirements

1. `tests/test_t0308_cancel_integration_restart.py` proves happy, boundary, malformed and rollback behavior of the production `server.jobs_cancel` across process restarts. It adds no production code.
2. Production `cancel` is a pure callable: it persists nothing, and this battery claims no durability guarantee for it. What is persisted is the test harness's own stream of decision records (the `cd1`-addressed receipts), written as canonical JSON under tmp_path with an atomic replace. A restart executes the production source anew in an isolated module namespace (the canonical module in sys.modules is never reloaded or mutated; `test_a_restart_never_touches_the_canonical_production_module` pins that) and the stream continues. Sampled streams (12 seeds restarted at every step, 10 with one random cut point, 3 with four steps each run in a real child interpreter) must give the same outcomes (type-exact: a bool is not an int) and the same durable log as an uninterrupted run and as the contract's reference implementation (`tests.test_t0302_cancel_contract`), the differential oracle.
3. Replaying the same seeded stream after restarts (6 seeds) gives identical outcomes, and decision ids are one per distinct request. Only the restart battery (T0353 family) mixes the real queue engine into its streams; this battery does not.
4. Forged or malformed requests are refused with the oracle's failure class and code, leave their input structurally identical (a serialized-value snapshot, not a hostile-identity proof), and the stream then continues. They are built from request fields only: cancel carries no previous record, so no digest-recomputed forgery family exists here (that family is T0326/T0344's). A truncated durable file is a host-level JSON error and never reaches the engine; the last good file stays usable.
5. Boundary rows pin the exact bounds a restarted engine can reach (status, attempts, seq, priority, lease and clock edges), with the oracle as the expected value. Persisted canonical JSON pins ascii-escaped encoding with a non-ASCII payload preimage row.

## Mutation check

Two author-run sweeps against this file alone, stopping at each mutant's first failing test; the generator and records are not checked in, so these tallies are author-run, not independently certified. Raw-crash kills (a wrong-accept sabotage whose wrongly-admitted input crashes downstream before any record exists, or an import-time failure) are kept separate from semantic kills, and every survivor was verified by an actual cross-file run, not by inspection.

Family 1 (the standard single-token set: comparison, boolean, return, offset, operator and integer-literal swaps; comments and docstrings not mutated): 91 mutants. 53 semantic kills, all plain outcome assertions (0 armed-hook or tripwire kills - this battery uses hook-free subclasses and no armed machinery, per the T0317 pattern). 5 raw-crash kills, each re-run without `-x` showing no assertion failure. 33 survivors of this file alone: this battery sweeps bounds relative to contract literals and carries a thin hostile-payload surface by design, so production validation mutants outside its reach survive here; 32 of the 33 were verified killed by actual cross-file runs against the T0306 exact unit rows (each killing test recorded: the now/seq/priority bound rows, `test_payload_depth_and_int_digits_are_exact`, `test_lowered_int_str_limit_fails_closed`, the malformed/hostile-payload rows, `test_lease_invariants_are_exact`, `test_done_and_dead_invariants_are_exact`, `test_requester_and_worker_grammar_is_exact`, `test_ready_record_is_exact_and_ordered`, `test_engine_matches_independent_model_on_random_requests`). The remaining survivor, `MAX_INT_BITS` 13288 -> 13289, is behavior-equivalent (pre-screen widening only; every int it newly admits has more than 4000 decimal digits and is rejected by the exact digit check), the same adjudication as T0306 and T0307.

Family 2 (identity/None/membership swaps, `fullmatch` -> `match`, `type(` -> `isinstance(`, per the T0317 precedent): 31 mutants. 16 semantic kills, all plain outcome assertions. 13 raw-crash kills, kept separate. 2 survivors of this file alone, both verified killed by actual cross-file runs: `fullmatch` -> `match` by `test_requester_and_worker_grammar_is_exact`, and the payload-walk `None` -> `0` by `test_ready_record_is_exact_and_ordered` (this battery's payloads carry no `None`, T0306's base payloads do).
