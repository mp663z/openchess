# T0312 Jobs/retry/fixture

## Requirements

1. tests/fixtures/retry/cases.json is a closed fixture for the T0311 jobs-retry contract: 4 happy, 8 boundary, 22 malformed and 3 rollback rows, one per line. Pinned records come from the T0311 reference decide.
2. Every row is pinned by name, a semantic manifest, a per-row edge check and a canonical sha256. Substituted, swapped, dropped or duplicated rows fail the semantic closure on its own, without the digest table.
3. Malformed rows cover every failure class (malformed_retry_request, invalid_retry_policy, clock_overflow). Each row has a single-locus minimal repair that decides. Rejections are fresh typed errors with retryable false, and the input stays unchanged.
4. Rollback rows cover every failure class. The rejected request stays bit-identical, and the valid follow-up decides as pinned.
5. Hostile-type rows are derived from every accepted request (48 requests, 52 variants each):
   - hostile containers on the request and the policy;
   - str-subclass keys in 3 forms on every request and policy field;
   - str-subclass, eq-raises and repr-raises values on the str fields;
   - int-subclass and bool values on the int fields and the policy fields.
   Each must fail typed, run no user code and leave the input unchanged.
6. Every one of the 17 T0311 reference mutants turns this fixture red. So do 19 extra fixture-level mutants covering the type/grammar guards, the bound edges, the clock edge and precedence. The T0311 equivalent edit keeps it green.

- R1, R2: `test_fixture_structure`, `test_fixture_scenario_closure`, `test_param_ids_equal_manifest_names`, `test_structure_mutations_fail`, `test_closure_kills_substitution_mutants`, `test_pinned_records`, `test_tampered_pinned_record_is_detected`.
- R3: `test_failure_class_and_enum_coverage`, `test_malformed`, `test_malformed_minimal_repair_succeeds`, `test_injected_valid_malformed_row_fails_rejection`, `test_validation_precedence`.
- R4: `test_rollback`.
- R5: `test_hostile_variants_of_every_accepted_request`, `test_variant_set_is_complete`.
- R6: `test_reference_is_green`, `test_reference_mutants_turn_the_fixture_red`, `test_fixture_edits_turn_the_fixture_red`, `test_fixture_edits_are_new`, `test_equivalent_edits_keep_the_fixture_green`.
