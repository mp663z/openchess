# T0315 Jobs/retry/unit/property

## Normative requirements

1. `tests/test_t0315_retry_unit_property.py` proves happy, boundary, malformed and rollback behavior of the production `server.jobs_retry.decide` (T0314) with unit rows and seeded properties. It adds no production code.
2. Every call is compared with an independent model written from the contract (integer arithmetic and a hand-built `rd1:` digest, no shared code with production): same record, or same failure class with the mapped code, `retryable` false, no cause or context.
3. Every call leaves the request byte-identical and returns a result that shares no container with it.
4. Every request and policy bound is pinned on both sides, hostile values (bool, float, NaN, bytes, str and int subclasses, inert str-subclass keys, missing, extra and non-str keys) are refused with the right class at every field, and the failure precedence is request, then policy, then clock.

## Requirement-to-test mapping

- Happy: `test_backoff_chain_and_exhaustion`, `test_record_is_exact_and_ordered`, `test_cap_applies_exactly_at_the_crossover`, `test_multiplier_one_is_constant_and_cap_equal_base_is_allowed`, `test_permanent_is_dead_at_every_attempt_and_ignores_the_clock`, `test_timeout_decides_like_transient_apart_from_the_bound_failure_name`, `test_no_jitter_and_determinism`, `test_decision_id_binds_every_request_field`.
- Boundary: `test_request_int_bounds_are_exact`, `test_policy_int_bounds_are_exact`, `test_clock_boundary_is_exact_and_never_clamped`, `test_huge_multiplier_power_is_exact_integer_arithmetic`, `test_job_id_grammar_is_exact`, `test_failure_names_are_exact_and_case_sensitive`.
- Malformed: `test_every_request_field_rejects_hostile_values`, `test_every_policy_field_rejects_hostile_values`, `test_subclasses_of_exact_types_are_refused`, `test_inert_str_subclass_keys_are_refused_at_both_levels`, `test_missing_extra_and_non_str_keys_are_refused`, `test_non_dict_requests_are_malformed`, `test_precedence_request_then_policy_then_clock`.
- Rollback: `test_rejected_requests_change_nothing_and_a_valid_follow_up_decides`, `test_result_shares_no_container_with_the_request_or_other_results`.
- Properties (seeded, replayable): `test_engine_matches_independent_model_on_random_requests` (40 seeds, half of the requests damaged), `test_delay_is_monotone_capped_and_exact_per_attempt`, `test_retry_at_is_now_plus_delay_and_overflow_is_the_exact_boundary`, `test_replay_is_deterministic_and_ids_are_unique_per_distinct_request`.

## Mutation check

41 single-token mutants of `server/jobs_retry.py` (comparison, boolean, return, offset, operator and integer-literal swaps) were run against this file alone, stopping at each mutant's first failing test. 40 are killed by semantic outcomes (an assertion, a model mismatch or a wrong typed class). 0 are killed only by a raw exception: a mutant whose first failure was a TypeError or KeyError was re-run without stopping and in each case also failed an assertion. The 1 survivor, `ensure_ascii=True` to `False` in the canonical encoder, is behavior-equivalent: every encoded string is ASCII by grammar.
