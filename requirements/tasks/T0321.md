# T0321 Jobs/progress/fixture

## Requirements

1. tests/fixtures/progress/cases.json is a closed fixture for the T0320 jobs-progress contract: 4 happy, 8 boundary, 32 malformed and 3 rollback rows, one per line. Pinned records come from the T0320 reference report and chain through previous: each linked step's previous is exactly the prior pinned record.
2. Every row is pinned by name, a semantic manifest, a per-row edge check and a canonical sha256. Substituted, swapped, dropped, duplicated or retyped rows fail the semantic closure on its own, without the digest table. Every pinned progress_id equals the hand-built contract preimage of its record.
3. Malformed rows cover every failure class (malformed_progress_request, corrupt_previous_record, progress_conflict), including same-arity renamed-key rows on the request and on the previous record, a forged previous (wrong percent_bp with a recomputed id), self-consistent forged previous records (each with a recomputed id) with done past total, total 2**53, total 0, reported_at 2**53 and op 'reprt' and both clock/total bounds one past the edge on the request and on the previous record. A boundary row (57 of 100 -> 5700) separates the exact floor from a float percent. Each row has a single-locus minimal repair that reports. Rejections are fresh typed errors with retryable false, and the input stays type-exactly unchanged.
4. Rollback rows cover every failure class. The rejected request stays type-exactly identical, and the valid follow-up reports as pinned.
5. Hostile-type rows are derived from every accepted request (55 requests; 45 variants for an unchained request, 97 or 99 for a chained one):
   - hostile containers (dict-subclass, lying dict, list-subclass) on the request and on the previous record;
   - str-subclass keys in 3 forms on every request and every previous-record field;
   - str-subclass, eq-raises, repr-raises and nested values on the str fields, and int-subclass and bool values on the int fields, of the request and of the previous record.
   Each must fail typed, run no user code and leave the input unchanged.
6. Every one of the 30 T0320 reference mutants (the battery as amended at 7d4e4dd) turns this fixture red. So do 27 extra fixture-level mutants covering the key, type, grammar and bound guards, the previous-record shape and done-bound checks, the previous-record op and total/done/clock bounds, the chain check, the percent formula (including float rounding) and the link. The T0320 equivalent edit keeps it green. Dropping the len clause of _exact_keys is equivalent (exact-str keys are unique) and is not listed.
