# T0324 Jobs/progress/unit/property

## Normative requirements

1. `tests/test_t0324_progress_unit_property.py` proves happy, boundary, malformed and rollback behavior of the production `server.jobs_progress.report` (T0323) with unit rows and seeded properties. It adds no production code.
2. Every call is compared with an independent model written from the contract (plain arithmetic and a hand-built `pg1:` digest, no shared code with production): same record, or same failure class with the mapped code, `retryable` false, no cause or context.
3. Every call leaves the request, including the previous record, byte-identical and returns a result that shares no container with it.
4. Every request and previous-record bound is pinned on both sides, previous-record defects are tested one at a time with the digest recomputed so only the named defect is present, the chain rules (same job, worker and total, no regression of done or time, terminal completion) and the failure precedence (request, then previous integrity, then chain) are exact, and hostile values (bool, float, NaN, bytes, subclasses, inert str-subclass keys, missing, extra and non-str keys) are refused at every field.

## Requirement-to-test mapping

- Happy: `test_first_report_has_no_previous_link_and_exact_shape`, `test_chain_links_each_record_to_the_previous_progress_id`, `test_percent_is_floor_in_basis_points`, `test_equal_done_is_a_heartbeat_and_equal_now_is_accepted`, `test_completion_is_reported_once_then_terminal`, `test_progress_id_binds_every_field`, `test_determinism_and_no_shared_containers`.
- Boundary: `test_request_bounds_are_exact`, `test_identifier_grammars_are_exact`, `test_previous_record_bounds_are_exact_with_a_valid_digest`, `test_chain_conflicts_are_exact`.
- Malformed: `test_every_request_field_rejects_hostile_values`, `test_subclasses_of_exact_types_are_refused`, `test_inert_str_subclass_keys_are_refused_in_request_and_previous`, `test_missing_extra_and_non_str_request_keys_are_refused`, `test_non_dict_requests_are_malformed`, `test_previous_field_defects_are_corrupt_even_with_a_valid_digest`, `test_previous_wrong_percent_is_corrupt`, `test_previous_digest_must_recompute`, `test_previous_missing_or_extra_keys_are_corrupt`, `test_precedence_request_then_previous_integrity_then_chain`.
- Rollback: `test_rejected_reports_change_nothing_and_the_valid_follow_up_reports`.
- Properties (seeded, replayable): `test_engine_matches_independent_model_on_random_chains` (40 seeds, 30% of requests damaged), `test_a_chain_never_goes_backwards_and_ends_at_completion`, `test_replay_is_deterministic_and_ids_are_unique_per_distinct_request`.

## Mutation check

82 single-token mutants of `server/jobs_progress.py` (comparison, boolean, return, offset, operator and integer-literal swaps) were run against this file alone, stopping at each mutant's first failing test. 81 are killed by semantic outcomes (an assertion, a model mismatch or a wrong typed class). 0 are killed only by a raw exception: a mutant whose first failure was a TypeError or KeyError was re-run without stopping and each also failed an assertion. The 1 survivor, `ensure_ascii=True` to `False` in the canonical encoder, is behavior-equivalent: every encoded string is ASCII by grammar.
