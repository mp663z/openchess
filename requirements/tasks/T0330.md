# T0330 Jobs/dead letter/fixture

## Requirements

1. tests/fixtures/dead_letter/cases.json is a closed fixture for the T0329 jobs-dead-letter contract: 4 happy, 10 boundary, 29 malformed and 3 rollback rows, one per line. Pinned dead-letter entries come from the T0329 reference bury.
2. Every row is pinned by name, a semantic manifest, a per-row edge check and a canonical sha256. Substituted, swapped, dropped, duplicated or retyped rows fail the semantic closure on its own, without the digest table. Every pinned payload_digest and entry_id equals the hand-built contract preimage.
3. Malformed rows cover every failure class (malformed_bury_request, corrupt_job, job_not_dead), including same-arity renamed-key rows on the request and on the job, now/seq/priority one past each bound and one below each floor, a job_id with a trailing newline, lease fields on a dead job, a dead job below max_attempts, payload depth 65, a 4001-digit payload int that passes the bit pre-screen (10**4000) and a lone surrogate. Each row has a single-locus minimal repair that buries. Rejections are fresh typed errors with retryable false, and the input stays type-exactly unchanged. Validation order is request shape, then job integrity (for dead and non-dead statuses), then the dead check.
4. PROVISIONAL, fail-closed: permanent_dead_below_max_provisional pins a permanent-failure dead job at attempts 4 as corrupt_job, following T0329, pending the owner ruling on the retry permanent-dead rule vs the queue dead invariant. The row is marked provisional in the fixture and its manifest.
5. Rollback rows cover every failure class. The rejected request stays type-exactly identical, and the valid follow-up buries as pinned.
6. Hostile-type rows are derived from every accepted request (48 requests, 84 variants each):
   - hostile containers (dict-subclass, lying dict, list-subclass) on the request, the job and the payload;
   - str-subclass keys in 3 forms on every request and job field;
   - str-subclass, eq-raises, repr-raises and nested values on the str fields, and int-subclass, bool and float values on the int fields, of the request and the job;
   - payload values JSON cannot store: NaN, inf, an aliased container, int / str-subclass / eq-raises keys, and str-subclass, repr-raises, int-subclass, float-subclass and tuple values.
   Each must fail typed, run no user code and leave the input unchanged.
7. Every one of the 32 T0329 reference mutants turns this fixture red. So do 11 extra fixture-level mutants covering the op, job-type and reason-type guards, the now/seq/priority floors, the job_id grammar, the status enum, the free-lease owner/expiry checks and the payload digest input. The T0329 equivalent edit keeps it green.
