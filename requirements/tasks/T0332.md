# T0332 Jobs/dead letter/implement

## Normative requirements

1. `server.jobs_dead_letter` implements `DeadLetterError`, `bury(request)` and `FAILURE_MAPPING` for data/contracts/dead_letter.yaml (contract id `jobs-dead-letter`). Production must not import or execute `tests.*`.
2. The request is checked first (`malformed_dead_letter_request`), then the job's integrity against every queue job invariant (`corrupt_job`), then its status (`job_not_dead`): exact types only, dict keys checked as exact strs before any set comparison, identifiers by ASCII fullmatch, bounded ints, payloads walked iteratively and without raising (exact built-in JSON, UTF-8 strs, ints of at most 4000 digits, finite floats, depth at most 64, no container met twice).
3. A buried job is dead with attempts equal to max_attempts whatever the reason (exhausted or permanent). The entry stores only the payload digest, never a copy, and carries its content-addressed entry_id. Errors are fresh typed DeadLetterErrors with no cause or context; the request is never changed.
4. The T0331 red battery turns green by replacing only its two binding lines. Every row, probe and mutant stays unchanged.

## Requirement-to-test mapping

- R1: `test_r2_production_imports_no_test_code`, `test_r3_public_surface`.
- R2, R3: `test_r4_every_fixture_request_agrees_with_the_reference` and `test_r5_production_and_reference_agree_on_hostile_variants` (every fixture request, and every field and nested field replaced by junk, dropped or given a sibling: same record or same failure class and code as the T0329 reference, request unchanged, no cause or context), `test_r5_hostile_subclasses_fail_closed_without_running_caller_code`, plus the full T0331 battery bound to `server.jobs_dead_letter`.
- R4: `test_r1_red_battery_switch_is_exactly_the_two_binding_lines` (switched back, the file hashes to the T0331 battery as landed; the oracle import stays and carries one extra F401 noqa).

## Mutation check

107 single-token production mutants (comparison, boolean, return, offset, operator and integer-literal swaps) were run against the T0331 battery plus the runtime proof. Every mutant of executable code dies except the `MAX_BITS` constant raised by one: that constant is a pre-screen only, and an int one bit past it already has 4001 digits, so the digit gate refuses it (behavior-equivalent). The remaining hits were mutations of comment text.

## Red/green transition

On main, switching the two T0331 binding lines to `server.jobs_dead_letter` fails at import because the module does not exist. With this change the same switch passes the whole T0331 battery.
