# T0333 Jobs/dead-letter/unit/property

## Normative requirements

1. `tests/test_t0333_dead_letter_unit_property.py` proves happy, boundary, malformed and rollback behavior of the production `server.jobs_dead_letter.bury` (T0332) with unit rows and seeded properties. It adds no production code.
2. Every call is compared with an independent model written from the contract (plain predicates, a recursive payload check and a hand-built `pd1:`/`dl1:` digest, no shared code with production): same record, or same failure class (`malformed_bury_request`, `corrupt_job`, `job_not_dead`) with the mapped code, `retryable` false, no cause or context.
3. Every call leaves the request byte-identical, checked with an iterative, cycle-safe structural snapshot that also covers cyclic and 5000-deep payloads, and returns a result that shares no container with it.
4. Request and job bounds are pinned on both sides, the queue job invariants (lease fields, attempts, status) are tested one at a time, the payload walk is exact (depth 64 and 65, alias and cycle, 4000 and 4001 int digits, finite floats, UTF-8 strings and keys, exact types), a lowered `sys.set_int_max_str_digits` (640) drives the ValueError refusal branch and is restored afterwards, the failure precedence (request shape, job integrity, dead status) is exact, and hostile values (bool, float, NaN, bytes, subclasses, inert str-subclass keys that run no caller code, missing, extra and non-str keys) are refused at every field.

## Requirement-to-test mapping

- Happy: `test_burial_has_exact_shape_and_binds_the_payload_by_digest`, `test_both_reasons_bury_a_dead_job`, `test_entry_id_binds_every_field_and_burial_is_deterministic`, `test_result_shares_no_container_with_the_request`.
- Boundary: `test_request_bounds_are_exact`, `test_job_bounds_are_exact`, `test_job_id_grammar_is_exact`, `test_valid_non_dead_jobs_are_not_dead`, `test_queue_job_invariants_make_a_job_corrupt`, `test_payload_depth_is_exact`, `test_payload_alias_and_cycle_are_refused`, `test_payload_int_digit_limit_is_exact`, `test_payload_int_digit_limit_under_a_lowered_interpreter_limit`, `test_payload_scalars_are_exact_json_values`, `test_payload_keys_must_be_exact_utf8_strs`.
- Malformed: `test_payload_str_subclass_keys_are_inert`, `test_payload_walk_runs_no_caller_code`, `test_every_request_field_rejects_hostile_values`, `test_every_job_field_rejects_hostile_values`, `test_missing_extra_and_non_str_keys_are_refused`, `test_inert_str_subclass_keys_are_refused_in_request_and_job`, `test_non_dict_requests_are_malformed`, `test_precedence_request_then_integrity_then_status`.
- Rollback: `test_rejected_calls_change_nothing_and_the_valid_follow_up_buries`.
- Properties (seeded, replayable): `test_engine_matches_independent_model_on_random_requests` (40 seeds), `test_random_corpus_covers_every_outcome`, `test_burial_is_deterministic_and_ids_are_unique_per_distinct_request`.

## Mutation check

107 single-token mutants of `server/jobs_dead_letter.py` (comparison, boolean, return, offset, operator and integer-literal swaps, plus edits of the comment and docstring text the mutator also reaches) were run against this file alone, stopping at each mutant's first failing test. 98 are killed by semantic outcomes (an assertion, a model mismatch or a wrong typed class). 0 are killed only by a raw exception. The 9 survivors are behavior-equivalent: 8 change only comment or docstring text (the `MAX_BITS` comment and the `_payload_ok` docstring), and 1 changes `MAX_BITS` from 13288 to 13289. That one is equivalent because any int of 13289 bits is at least 2**13288, which already has 4001 digits and is refused by the digit check.
