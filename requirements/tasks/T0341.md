# T0341 Jobs/limit/implement

## Normative requirements

1. `server.jobs_limit` implements `LimitError`, `admit(request)` and `FAILURE_MAPPING` for data/contracts/limit.yaml (contract id `jobs-limit`). Production must not import or execute `tests.*`.
2. Checks run in this order: request shape (`malformed_limit_request`), policy bounds (`invalid_limit_policy`), cost within capacity (`malformed_limit_request`), previous bucket integrity (`corrupt_previous_bucket`), chain (`limit_conflict`), clock (`clock_overflow`). Exact types only, dict keys checked as exact strs before any set comparison, key and `lm1:` limit_id by ASCII fullmatch, bounded ints. A previous record is trusted only if its shape, bounds, decision invariants (including the exact deny retry window) and limit_id recompute.
3. A keyed token bucket gains one token per `refill_ms`; a fresh bucket (previous null) is full. At capacity no partial refill is banked (updated_at jumps to now). The request is admitted when the refilled tokens cover the cost, otherwise denied with the exact retry_after_ms; a deny whose now + retry_after_ms passes 2**53-1 is `clock_overflow`, never clamped. key, capacity and refill_ms must equal the previous record's and now must not precede its updated_at. Errors are fresh typed LimitErrors with no cause or context; the request is never changed.
4. The T0340 red battery turns green by replacing only its two binding lines. Every row, probe and mutant stays unchanged.

## Mutation check

96 single-token production mutants (comparison, boolean, return, offset, operator and integer-literal swaps) were run against the T0340 battery plus the runtime proof, stopping at each mutant's first failing test. 94 mutants are killed and none of them by a raw crash: a kill counts only when the first failure is a semantic outcome, which is an assertion (53) or a wrong typed refusal or detected caller-code run (41). Raw exceptions (TypeError, KeyError, AttributeError and the like) are tallied separately and there were 0 of them, so no mutant relies on a crash. The 2 survivors are stated as behavior-equivalent or non-code: `ensure_ascii` in the canonical encoder (every encoded string is ASCII by grammar), and `tokens < cost` to `<=` in the deny-record check (the retry-window clauses that follow already force tokens below cost).

## Red/green transition

On main, switching the two T0340 binding lines to `server.jobs_limit` fails at import because the module does not exist. With this change the same switch passes the whole T0340 battery.
