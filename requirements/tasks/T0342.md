# T0342 Jobs/limit/unit/property

## Normative requirements

1. `tests/test_t0342_limit_unit_property.py` proves happy, boundary, malformed and rollback behavior of the production `server.jobs_limit.admit` (T0341) with unit rows and seeded properties. It adds no production code.
2. Every call is compared with an independent model written from the contract (integer token-bucket arithmetic and a hand-built digest, no shared code with production): same record, or same failure class with the mapped code, `retryable` false, no cause or context.
3. Every call leaves the request, including the previous record, byte-identical and returns a result that shares no container with it.
4. Request, policy and cost bounds are pinned on both sides, previous-record defects are tested one at a time with the digest recomputed, admit and deny invariants and the `updated_at + retry_after_ms` clock sum are exact at the boundary, the chain rules and failure precedence are exact, and hostile values (bool, float, NaN, bytes, subclasses, inert str-subclass keys, missing, extra and non-str keys) are refused at every field.

## Requirement-to-test mapping

- Happy: `test_fresh_bucket_is_full_and_admits_with_exact_shape`, `test_drain_then_deny_with_exact_retry_then_refill`, `test_partial_refill_is_carried_below_capacity`, `test_at_capacity_no_partial_refill_is_banked`, `test_deny_does_not_consume_tokens_and_is_chained`, `test_limit_id_binds_every_field_and_decisions_are_deterministic`, `test_result_shares_no_container_with_the_request`.
- Boundary: `test_policy_and_cost_bounds_are_exact`, `test_key_grammar_is_exact`, `test_clock_overflow_boundary_is_exact_and_never_clamped`, `test_equal_now_is_accepted_and_regression_conflicts`, `test_previous_admit_and_deny_invariants_are_exact`, `test_forged_deny_retry_sum_boundary_is_inclusive`, `test_forged_deny_retry_window_depends_on_tokens_held`, `test_chain_requires_same_key_capacity_and_refill`.
- Malformed: `test_every_request_field_rejects_hostile_values`, `test_every_policy_field_rejects_hostile_values`, `test_subclasses_of_exact_types_are_refused`, `test_inert_str_subclass_keys_are_refused_at_every_level`, `test_missing_extra_and_non_str_keys_are_refused`, `test_non_dict_requests_are_malformed`, `test_previous_field_defects_are_corrupt_with_a_valid_digest`, `test_previous_digest_must_recompute`, `test_previous_missing_or_extra_keys_are_corrupt`, `test_precedence_request_policy_cost_previous_chain_clock`.
- Rollback: `test_rejected_calls_change_nothing_and_the_valid_follow_up_decides`.
- Properties (seeded, replayable): `test_engine_matches_independent_model_on_random_chains`, `test_admitted_cost_never_exceeds_capacity_plus_refill_earned`, `test_deny_retry_after_is_exact`, `test_replay_is_deterministic_and_ids_are_unique_per_distinct_request`.

## Mutation check

96 single-token mutants of `server/jobs_limit.py` (comparison, boolean, return, offset, operator and integer-literal swaps) were run against this file alone, stopping at each mutant's first failing test. 94 are killed by semantic outcomes (an assertion, a model mismatch or a wrong typed class). 0 are killed only by a raw exception. The 2 survivors are behavior-equivalent: `ensure_ascii=True` to `False` in the canonical encoder (every encoded string is ASCII by grammar), and `tokens < cost` to `tokens <= cost` in the previous-deny check (the following retry-window bounds already reject the equal case).

A lane review found one more real survivor that the mutator's operator set does not generate: `-` to `+` in `(cost - tokens) * refill_ms` (the previous-deny retry window upper bound) and in its lower-bound twin. Every earlier forged deny held `tokens` 0, which hides the difference. `test_forged_deny_retry_window_depends_on_tokens_held` now forges denies with `tokens` above 0 and checks `lo`, `lo + 1`, `hi` and `hi + 1` of the window for five cost and token pairs, including cost 2, tokens 1, retry 1001 as `corrupt_previous_bucket`. Both `-` to `+` mutants were re-run by hand and are killed by assertions (1 and 79 failing tests).
