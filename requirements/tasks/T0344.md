# T0344 Jobs/limit/integration/restart

## Normative requirements

1. `test_t0344_limit_integration_restart.py` proves happy, boundary, malformed and rollback behavior of the production `server.jobs_limit` across process restarts. It adds no production code.
2. The durable value of the engine is persisted as canonical JSON under tmp_path (atomic replace), the production file is executed anew in an isolated module namespace (the canonical module in sys.modules is never reloaded or mutated; `test_a_restart_never_touches_the_canonical_production_module` pins that), and the stream continues. Sampled streams (12 restarted at every step, 10 with one random cut point, 3 with four steps each run in a real child interpreter) must give the same outcomes and the same durable value as an uninterrupted run and as the contract's reference implementation (`tests.test_t0338_limit_contract`), which is the differential oracle.
3. Replaying the same seeded stream after restarts (6 seeds) gives identical outcomes, and receipt identifiers are one per distinct receipt. Only the restart battery (T0353) mixes the real queue engine into its streams.
4. Forged or malformed inputs are refused with the oracle's failure class and code, leave their input structurally identical, and the next valid request still succeeds. They are built from the persisted value when it is a previous record or a queue state (fields dropped or retyped, digest not recomputed), and from the request fields otherwise (retry and dead-letter carry no previous record). Digest-recomputed forgeries are generated where a previous record exists (T0326, T0344) and not elsewhere. A truncated durable file is a host-level JSON error and never reaches the engine; the last good file stays usable.
5. Boundary rows pin the exact bounds a restarted engine can reach, with the oracle as the expected value.

## Mutation check

161 single-token mutants of `server/jobs_limit.py` were run against this file, stopping at each mutant's first failing test: comparison, boolean, return, offset, operator swaps, integer-literal swaps including the literals 0 and 1, and the arithmetic swaps `-`/`+`, `*`/`//`, `*`/`-`, `**`/`*`, `%`/`//`. Comment and docstring text is not mutated. 155 were killed, 2 are crash-only and are not counted as kills (`operations[1]` and `operations[2]` in the contract loader raise IndexError at import time, so no test runs), and 4 survived. All 4 are behavior-equivalent: `ensure_ascii=True` to `False` (every digested string is ASCII by grammar); previous `capacity` lower bound 1 to 0 (a record with capacity 0 is still refused because `cost` must lie in 1 through `capacity`); previous deny `retry_after_ms` lower bound 1 to 0 (a positive deficit window already forces it above 0); and `tokens < cost` to `<=` in the deny check (the retry window bounds already refuse the equal case). The same four are documented for the T0343 fuzz battery. The sweep ran while the file lacked its last two rows (the hook-free subclass row and the canonical-module identity row, both added afterwards); those rows can only add kills, so no survivor was added by them, but the tallies describe the file without them and no post-fix full re-sweep was run.

A second sweep with an identity/None/membership operator set (`is not None` to `is not 0`, `is`/`is not`, `in`/`not in`, `None` to `0`, `True`/`False`, `fullmatch` to `match`, `type(` to `isinstance(`) was run on the same earlier file: 68 mutants, 67 killed, 1 survivor (`ensure_ascii` via `True` to `False`, equivalent). Exact-type predicates: every `type(x) is T` site in the production file (9 sites) was swapped to `isinstance(x, T)` one at a time against the final file; `test_hook_free_subclasses_at_every_path_are_refused_like_the_oracle` replaces every value, container and dict key of sampled valid requests (previous record included) with a hook-free subclass of the same value and requires the oracle's outcome; all 9 swaps fail by oracle mismatch.

The forged-previous and clock rows (`test_forged_previous_records_with_a_valid_digest_match_the_oracle_field_by_field`, `test_forged_deny_retry_window_and_clock_sum_match_the_oracle_on_a_full_grid`, `test_deny_clock_overflow_edge_matches_the_oracle_at_every_offset`) recompute the `limit_id` so only the named defect is present.

These are author-run tallies and are not independently certified. A kill here includes a failure raised by an armed object's hook or a reference-oracle mismatch; the sweep does not split those from other assertion kills, and crash-class kills (a foreign exception instead of the typed refusal) are not separated per mutant.
