# T0348 Jobs/restart/fixture

## Requirements

1. tests/fixtures/restart/cases.json is a closed fixture for the T0347 jobs-restart contract: 4 happy, 15 boundary, 41 malformed and 2 rollback rows, one per line. Each happy/boundary row applies its requests in turn to one evolving queue state and pins every receipt and every committed state computed by the T0347 reference restart.
2. Every row is pinned by name, a semantic manifest, a per-row edge check and a canonical sha256. Substituted, swapped, dropped, duplicated, retyped or second-defect rows fail the semantic closure on its own, without the digest table. Every pinned restart_id equals the hand-built contract preimage of its record, and every prior_state_id/state_id equals the queue state id of the state before/after the step. Each committed step changes only the released jobs (leased -> ready, lease cleared, attempts kept).
3. Happy and boundary rows cover releasing the worker's own unexpired leases in seq order, a mixed state (an expired lease, another worker's lease, a max-attempts lease and ready/done/dead jobs untouched), idempotent repeat, a worker holding no lease, expiry one after now and equal to now, now 0, now and expiry at 2**53-1, the empty queue, a 64-character worker, a next_seq gap, next_seq 2**53-1, priorities 0 and 9, payload depth 64, payload ints of 4000 digits (positive and negative) and a non-ASCII payload (non-ASCII-kept queue canon).
4. Malformed rows cover both failure classes (malformed_restart_request, corrupt_queue), including:
   - same-arity renamed-key rows on the request and the state;
   - worker grammar (a space, a trailing newline, 65 characters), now -1, 2**53 and bool;
   - next_seq -1, 2**53 and not past the last seq; a repeated seq; a duplicate job_id; a job_id with a trailing newline;
   - priority -1 and 10, attempts -1 and 6, a leased job with attempts 0, expiry 0 or 2**53, a bad or newline-ended lease_owner; lease fields on a ready or done job; a dead job below max attempts; a done job at attempts 0; an unknown status;
   - payload depth 65, a 4001-digit int, a lone surrogate in a value and in a key;
   - a bad request with a corrupt state (the request check wins).
   Each row has a minimal repair that commits (single-locus except the precedence row). Rejections are fresh typed errors with retryable false, and the state and request stay type-exactly unchanged.
5. Rollback rows cover both failure classes. The rejected state and request stay type-exactly identical, and the valid follow-up commits as pinned.
6. Hostile-type rows are derived from every accepted input (63 state/request pairs; 39 variants for the empty queue, 103 to 112 otherwise):
   - hostile containers (dict-subclass, lying dict, list-subclass) on the request, the state and the first job; a list-subclass and a tuple jobs list;
   - str-subclass keys in 3 forms on every request, state and job field;
   - str-subclass, eq-raises, repr-raises and nested values on the str fields, and int-subclass, bool, float and float-subclass values on the int fields, of the request, the state and the first job (including a non-null lease_owner and lease_expires_at);
   - payloads JSON cannot store: hostile containers, keys and values, a tuple, a set, NaN and -inf, a cycle, an alias within one payload and an alias across two jobs.
   Each must fail typed, run no user code and leave both inputs unchanged.
7. The job-count bound is checked on derived states: 10000 jobs commit, 10001 are corrupt_queue (the bound is read from the queue contract, not from the reference under test).
8. Every one of the 52 T0347 reference mutants turns this fixture red through executed rows (pinned, malformed, rollback, hostile probes, precedence or the job-count check); no source-text or table-shape check counts. So do 16 extra fixture-level mutants: grammar fullmatch weakened to match, the job-count, depth and digit bounds made strict, the payload alias check and its record dropped, the priority floor, the expiry, next_seq and now ceilings, the idle expiry arm, the op and status type checks, the done invariant made strict, and the seq and job_id trackers dropped. The 3 T0347 equivalent edits keep it green.
