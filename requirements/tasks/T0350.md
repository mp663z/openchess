# T0350 Jobs/restart/implement

## Normative requirements

1. `server.jobs_restart` implements `RestartError`, `restart(state, request)` and `FAILURE_MAPPING` for data/contracts/restart.yaml (contract id `jobs-restart`). Production must not import or execute `tests.*`.
2. The request {op, worker, now} is checked first (`malformed_restart_request`), then the state against every queue state and job invariant (`corrupt_queue`): exact types only, dict keys checked as exact strs before any set comparison, identifiers by ASCII fullmatch, bounded ints, payloads walked iteratively and without raising (exact built-in JSON, UTF-8 strs, ints of at most 4000 digits, finite floats, depth at most 64, no container met twice across a state).
3. Every job leased by the worker whose lease is live (now strictly before its expiry) returns to ready with no owner or expiry; attempts are kept, expired leases are left for the queue claim, and a released job at max_attempts stays ready. The receipt lists released ids in seq order, binds the state before and after with the queue state_id, and carries its `rst1:` restart_id. The new state is committed last, in place; a rejected call leaves state and request unchanged. Errors are fresh typed RestartErrors with no cause or context.
4. The T0349 red battery turns green by replacing only its two binding lines. Every row, probe and mutant stays unchanged.

## Mutation check

118 single-token production mutants (comparison, boolean, return, offset, operator and integer-literal swaps) were run against the T0349 battery plus the runtime proof. 107 die; the remaining 11 are behavior-equivalent or comment text: the `MAX_BITS` pre-screen constant (an int past it already has 4001 digits and the digit gate refuses it), `ensure_ascii` in the receipt encoder (receipt strings are ASCII by grammar), the receipt encoding name (ASCII text encodes identically), and docstring wording.

## Red/green transition

On main, switching the two T0349 binding lines to `server.jobs_restart` fails at import because the module does not exist. With this change the same switch passes the whole T0349 battery.
