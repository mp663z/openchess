# T0351 Jobs/restart/unit/property

## Normative requirements

1. `tests/test_t0351_restart_unit_property.py` proves happy, boundary, malformed, corrupt-queue and rollback behavior of the production `server.jobs_restart.restart` (T0350) with unit rows and seeded properties. It adds no production code.
2. Every call is compared with an independent model written from the contract (plain predicates for the request and every queue state and job invariant, an independent lease release and a hand-built `qs1:` and `rst1:` digest, no shared code with production): same receipt and same new state, or same failure class (`malformed_restart_request`, `corrupt_queue`) with the mapped code, `retryable` false, no cause or context.
3. A rejected call leaves state and request unchanged, checked with an iterative, cycle-safe structural snapshot that also covers cyclic and 5000-deep payloads. An accepted call changes the state in place and only the leased jobs of the named worker whose lease expires strictly after `now`; attempts, other jobs, job order and `next_seq` are kept, and the receipt shares no container with the state.
4. The strict expiry boundary (`now` 99, 100 and 101 against expiry 100), the worker and request bounds, the corrupt_queue battery (state and job shape, seq order and `next_seq`, 10000 and 10001 jobs, duplicate ids, lease invariants, per-field hostile values), the payload walk (depth 64 and 65 through lists and dicts, alias and cycle also across two jobs, 4000 and 4001 int digits, floats, UTF-8 strings and keys), a lowered `sys.set_int_max_str_digits` (640, restored afterwards), the precedence (request before state), idempotence of a second restart and hostile values (bool, float, NaN, bytes, subclasses, inert str-subclass keys, missing, extra and non-str keys) are pinned.

## Requirement-to-test mapping

- Happy: `test_restart_releases_only_unexpired_leases_of_the_worker`, `test_expiry_boundary_is_strict`, `test_empty_release_is_a_successful_receipt_with_unchanged_state`, `test_second_restart_at_the_same_now_releases_nothing`, `test_attempts_are_never_refunded_or_charged_and_max_attempts_returns_to_ready`, `test_released_ids_are_in_seq_order_with_gaps_in_seq_numbers`, `test_restart_id_binds_worker_clock_and_states`, `test_state_id_keeps_non_ascii_and_receipt_shares_nothing`, `test_state_is_updated_in_place`.
- Boundary: `test_request_bounds_are_exact`, `test_worker_grammar_is_exact`, `test_job_count_bound_is_exact`, `test_seq_ordering_and_next_seq_bound_are_exact`, `test_payload_walk_depth_alias_cycle_and_scalars`, `test_alias_across_two_jobs_payloads_is_corrupt`, `test_payload_int_digit_limit_is_exact`, `test_payload_int_digit_limit_under_a_lowered_interpreter_limit`.
- Malformed: `test_every_request_field_rejects_hostile_values`, `test_missing_extra_and_non_str_request_keys_are_refused`, `test_non_dict_requests_are_malformed`, `test_inert_str_subclass_keys_are_refused`, `test_state_shape_defects_are_corrupt`, `test_job_field_defects_are_corrupt`, `test_payload_walk_runs_no_caller_code`, `test_precedence_request_before_state`.
- Rollback: `test_one_corrupt_job_among_many_rejects_the_whole_state_unchanged`, `test_rejected_calls_change_nothing_and_the_valid_follow_up_restarts`.
- Properties (seeded, replayable): `test_engine_matches_independent_model_on_random_states` (40 seeds), `test_random_corpus_covers_every_outcome_and_both_release_shapes`, `test_restart_is_idempotent_and_never_touches_other_workers` (10 seeds).

## Mutation check

118 single-token mutants of `server/jobs_restart.py` (comparison, boolean, return, offset, operator and integer-literal swaps, plus edits of the comment and docstring text the mutator also reaches) were run against an earlier revision of this file alone, stopping at each mutant's first failing test. 106 were killed by semantic outcomes (an assertion, a model mismatch or a wrong typed class), 0 only by a raw exception. Of the 12 survivors, the dict-branch depth mutant (`depth + 1` to `depth + 0` in `_payload_ok`) was a real gap; a depth test through dicts and mixed containers was added and that mutant was re-run by hand and is now killed, giving 107 kills. The other 11 are behavior-equivalent: 7 change only comment or docstring text, `MAX_BITS` 13288 to 13289 (any int of 13289 bits is at least 2**13288, which already has 4001 digits and is refused by the digit check), `ensure_ascii=True` to `False` in the receipt canon and `utf-8` to `utf-7` when encoding it (the receipt holds only ASCII from the worker grammar and derived ids, and has no `+`).
