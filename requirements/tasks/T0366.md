# T0366 Privacy/cloud-off/fixture

## Requirements

1. `tests/fixtures/cloud_off/cases.json` is a closed fixture for the T0365 cloud-off contract: 8 happy, 16 boundary, 91 malformed and 8 rollback rows. Each row is a scenario replayed in order on one fresh world, the T0365 reference `CloudSwitch` composed with the T0356 `FlagStore`. Pinned results come from that reference.
2. Every row is pinned by a name manifest, a per-row sha256 digest and a replay checked against the pinned results. A substituted, swapped, dropped, duplicated or retyped row fails the closure, with or without the digest table. A silent retype that keeps replay green is caught by the digest table alone.
3. Malformed rows cover all seven failure classes, each with a minimal repair that succeeds. Rejections are typed `CloudError` values with the pinned code. The request, the switch state and the flag state stay unchanged. `collection_sensitive` and `cloud_mode_off` both map to the `cloud_off` code and stay distinct failure classes.
4. Boundary rows pin the revision edge (MAX-1 commits to MAX, a change at MAX is `revision_exhausted` for turn on and for the kill switch, a same-value set at MAX is a no-op), the check order (malformed, unknown install, stale, same-value no-op, opt-in, exhaustion; switch before flag), the opt-in binding to install and revision, the sha256 known answer for `ins1:<1*64>|0|on`, the kill switch needing no opt-in, a verdict read at send time, and unknown install or collection reading off or sensitive.
5. Opt-in preimage variants (target off, colon separator, trailing separator, leading zero, plus sign, uppercase target, utf-16) are each `opt_in_missing`. Grammar violations (prefix, length, case, type, trailing newline) are `malformed_cloud_request`, including on a turn off.
6. Rollback rows cover every failure class: the rejected request leaves switch and flag state unchanged and the follow-up behaves as pinned.
7. Hostile-type variants are derived from every accepted verdict and transition request (dict and list containers, str-subclass, eq-raises and hash-colliding keys, dropped, extra and int keys, str-subclass, eq-raises, repr-raises, bytes and empty values, bool, int-subclass and float revisions). Each fails `malformed_cloud_request`, runs no user code and leaves the input and both states unchanged.
8. 27 reference mutants (default on, re-register reset, opt-in ignored or unbound, kill switch needing opt-in, no compare-and-set, same-value bumps or needing opt-in, saturation and wrap, exhaustion check order, unknown reads on, off not applied, flag ignored or checked first, unknown collection allowed, cached verdict, local blocked, subclass and bool leniency) each turn the fixture red by a pinned mismatch or a failed hostile variant. 15 fixture edits are each caught by the closure, in both digest and closure-only modes.
