# T0446 Contracts/errors/contract

Source: `data/contracts/control-plane.yaml` schema_version 2, `contract.transport.errors`. The pure classifier reads the source closed_enum and exact declared error shape; it does not invent per-code HTTP statuses (T0419 owns status grouping). An HTTP 2xx is success even with an `error` property; an HTTP 4xx or 5xx has a declared error object with code, message and retryable of exact built-in types. Additional error fields may be carried, including at top level, but private content and key material cannot leak. Unsupported 1xx/3xx have no contract payload semantics and are refused as a stated fail-closed reading. Malformed and hostile source/status/payload are fresh typed errors and leave inputs unchanged. A later implement task must independently implement the classifier.
