# T0477 Replaceable control-plane unit/property

`tests/test_t0477_control_plane_properties.py` exercises the shipped consumer-side `server/control_plane_client.py` through the T0474 conforming mock and controlled failing transports. It is additive to T0476's concrete regression and mutant battery, not a second implementation of the client.

Deterministic property families use fixed seeds and enumerate edges. Delivered-but-lost replies on quota.reserve cause one effect and one Idempotency-Key across retries; independent operations get distinct keys. Entitlements cache serves while age is less than TTL and degrades to the free tier at TTL, with token lifetime not crossing the cache probe. Refresh is inclusive at the skew edge and local token expiry refuses without sending. Reservation expiry is inclusive and commit/release have distinct local outcomes. Required fields reject hostile value types before transport. New response fields are dropped from the returned projection. A request is not mutated; key material stays out of logs; numeric success fields reject non-finite or boolean values. A closed enum error remains typed.
