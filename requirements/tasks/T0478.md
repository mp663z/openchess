# T0478 Replaceable control-plane fuzz/fault

`tests/test_t0478_control_plane_fuzz_fault.py` targets the shipped `server/control_plane_client.py`, seeded with 7, 42, 1337 and 90210. The T0474 mock certifies actual server-side idempotency for before/after-delivery failures, retryable 503s and malformed 2xx; it does not serve as a second client. Other schedules pin retry exhaustion with uncertain remote success, cache at and before TTL under outages, auth failure despite a warm cache, local reservation expiry, and 60 randomized malformed requests per seed. Seven source edits are compiled into separate modules and must fail a targeted behavioral probe each. Existing T0476/T0477 tests cover the full declarative contract and hostile key/value boundary; this suite adds multi-attempt failure trajectories rather than copying those tests.

Rollback has two meanings here: after an exhausted reply-loss sequence the client has no locally committed reservation, but the mock may already have accepted it. There is no claim of server rollback or automatic cancel. An invalid 2xx is terminal even if the mock accepted the original request. Reservation shortcut tests use an injected clock and assert local tracking only; mock server expiry has its own wall clock. Process restart and persistence are T0479, not this suite. No new product semantics are introduced.

Run: `uv run --with pytest --with pyyaml --with ruff pytest -q tests/test_t0478_control_plane_fuzz_fault.py` and `uv run --with ruff ruff check tests/test_t0478_control_plane_fuzz_fault.py`.
