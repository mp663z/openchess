# T0548 Import/multi-PGN/contract

`tests/test_t0548_import_multi_pgn_contract.py` is a pure reference battery for the `import-multi-pgn` scenario in `data/contracts/import.yaml`. It is permanently green against `reference_import`; T0550 swaps only the named `PRODUCTION_BINDING` to an adapter around its shipped pgn-multi importer. It must not bind to today's `ingest.import_pgn.run_import_pgn`, whose `import-pgn` intake deliberately refuses `pgn-multi`. No production dispatch is changed here.

The scenario's directly stated requirements are source `pgn-multi` (a user-owned file, rights class `user-own`), visible `import-summary`, per-game atomic records, provenance and index entries, and started/stored/completed telemetry. Malformed input has code `malformed_request`; the closed error shape and source-refusal rule come from the shared contract. The battery checks two valid games, duplicate within a file, malformed first/later game, and wrong-source refusal. Five black-box mutants alter provenance, count, event cardinality, game iteration, or rollback; each is red against behavioral probes that call the binding.
