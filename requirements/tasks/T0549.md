# T0549 Import/multi-PGN/rights fixture

`tests/test_t0549_import_multi_pgn_rights_fixture.py` pins the rights behavior of the `pgn-multi` source against `data/contracts/import.yaml` and `data/contracts/rights_policy.yaml`: registry class `user-own`, policy flags (never redistributed, no third-party storage, provenance required), `user-own` provenance on every stored record and index entry, rights unchanged on re-import, and refusal (`unknown_rights`, no state, no telemetry) for every other source id including case and whitespace variants.

It runs against T0548's `PRODUCTION_BINDING`, so T0550 re-runs these rows against the shipped importer without edits. The fixture is the T0538 digest-pinned `tests/fixtures/import_rights/multi_game.pgn`, not a copy. The shipped single-file runner is asserted to still refuse `pgn-multi` until T0550 owns that dispatch.

Not asserted: byte-stream interface, compression, and illegal-move handling (T0592 chain).
