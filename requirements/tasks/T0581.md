# T0581 Import/truncated/contract

`tests/test_t0581_import_truncated_contract.py` is the pure reference battery; T0583 (verified in tasks/dag.json) replaces its `PRODUCTION_BINDING`. Both pgn-file and pgn-multi are in scope. Three truncated/unterminated PGN cases refuse as malformed_request with the explicitly declared `refusal-with-location`, one persisted rejection record, and exact started/game_rejected/completed telemetry. No game record, index entry or import summary is written. Three black-box mutants drop the location, record or completed event and are red through a binding probe.

Import.yaml does not shape the location or rejection record. T0537's path reports unstructured exception text only. Fail-closed narrow reading: `{game_number: 1, line: N}` identifies the EOF line in the refused game (one-based), and the rejection record contains kind, source_id, game_number, code, detail and location. These keys, line base and EOF choice are flagged for owner review; byte offset and column are open, not guessed.

Production divergence for T0583: `ingest/import_pgn.py@ea0c9f94f8b87107e7a51e82d620e7ecd0d15097` raises ImportFailure from MalformedPGN without a rejection record or game_rejected/completed events. It cannot be treated as a conforming refusal path. The pure reference reuses T0537's PGN validator syntax only, not its conflicting failure outcome.

The line (or ply for an illegal move) is relative to the rejected game, not the full file. A valid game 1 followed by rejected game 2 returns game_number 2 and a game-relative marker. Intake of an out-of-scenario source ID is Refusal(unknown_rights) with no state or telemetry.
