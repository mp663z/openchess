Open owner decision: cross-source re-import of the same game_id. T0537's canonical content_sha256 includes source_id, so an otherwise identical game from another source has a different content hash and reads as an update. The import.yaml idempotency rule names game_id as the dedup key and says a same-hash re-import is a no-op; whether source identity should count as a content change for cross-source re-import needs an owner decision. No battery row pins either interpretation until the owner resolves that tension.
