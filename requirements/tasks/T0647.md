# T0647 Import/cancel/contract test

`tests/test_t0647_import_cancel_contract.py` is a pure reference battery; T0649 replaces only `PRODUCTION_BINDING`. It reads `import.yaml` directly: the three allowed sources are pgn-file, pgn-multi and pgn-folder; the output is a cancelled-summary, persisted state contains committed games only, telemetry is import.started/import.cancelled, and the atomicity rule preserves committed games while discarding the in-flight game. The test-owned `cancel_at` ordinal is a deterministic cancellation boundary, not a proposed product callback or timing contract. Rows cancel before game 1, 2 and 3 for all three sources, including between files in a folder. Separate rows put an illegal or malformed game exactly at the cancel boundary and prove that it is neither validated nor persisted; a folder illegal game at that boundary also cancels without a refusal. Record and index membership is checked, not merely summary counts. An update keeps its superseded content-addressed record but no new orphan beyond the old and newly indexed record. A re-run counts earlier committed games as already imported; an in-input duplicate counts 1 imported/1 already; a changed-content game with the same identity counts 1 updated before cancellation. Each result is accumulated from the T0537 reference importer, not inferred from game ordinal. Nine black-box bindings change output kind, discard the prefix, commit the in-flight game, leave an orphan in-flight record, process a later game, omit cancellation telemetry or falsify the count, infer it from the ordinal or leave an orphan after an update; each is red through a behavioral probe.

The contract does not specify a cancellation API or the timing of a cancellation request within a game. The reference uses T0537's exact `source_id`, `games_imported`, `games_already_imported`, and `games_updated` count fields, with the `kind` changed to `cancelled-summary`, and cancels before committing the selected game. The trigger is a test seam, not a public API. Cancel after all games, cancel during a refusal, double cancel and timing inside an in-flight game are open coordinator questions and unpinned here. For pgn-file/pgn-multi, a malformed or illegal game reached before cancel ends as refusal and delegates the outcome to the landed T0570/T0581/T0592 reference model: started, a game_stored for a committed prefix, game_rejected and completed, with a located rejection record and no cancel event/summary. The shared splitter separates a two-line unclosed game 2 before a following game 3, so T0570 locates its unmatched brace/variation opener at line 11 rather than the game's last line 12; a final-game two-line unterminated construct, or a final game lacking a terminal result token, follows T0581 at last line 12. The classifier uses the validator's actual missing-result detail (`movetext missing terminal result token (truncated?)`) and the game's position within the split stream. For pgn-folder, a malformed game follows T0636 reject-and-continue until the cancel boundary; the run then returns cancelled-summary with import.cancelled, without import.completed or any game at/after that boundary. A row with malformed game 1 in a.pgn and cancellation before game 2 in b.pgn pins zero indexed records and zero committed-game counts. Whether a prior rejection record persists in that cancelled folder run, and whether import.game_rejected appears in its telemetry, are open owner questions; no row asserts or forbids either. An illegal game in a folder before cancellation delegates to T0636 from the unmutated store, preserving the shared model's committed prefix and game_stored event without replay or duplicate started/cancelled events. Valid-game-then-illegal and malformed-game-then-illegal rows check the full ordered outcomes against that model. The folder scenario lists only malformed_request, so its current illegal_move refusal is provisional and joins the open owner question of illegal_move vs malformed_request. A cancellation triggered during refusal also remains open. Folder path and shape preflight matches T0636: no nested/slash/backslash paths, `.pgn` or `..pgn` names, non-PGN paths or non-string content; these refuse before state. For a wrong source, it refuses before any state; this follows the contract's fail-closed source registry.

Production divergence for T0649: `ingest/import_pgn.py` currently handles the import-pgn scenario for pgn-file only and has no cancellation API, cancelled-summary, or import.cancelled event. This battery does not edit or claim to exercise that shipped runner. The production implementation task must replace its reference binding and satisfy the rows.
